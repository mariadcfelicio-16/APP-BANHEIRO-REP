# Agenda da República — Banheiro

Aplicativo web instalável (PWA), já configurado para usar o projeto Supabase informado.

## Recursos
- Login por e-mail e senha
- Quarto vinculado ao usuário
- Próxima limpeza em destaque
- Rodízio semanal de 01/08/2026 a 26/12/2026
- Marcação de limpeza feita ou atrasada
- Ranking e pontuação por quarto
- Calendário compartilhado para registrar retirada do lixo
- Histórico de limpezas e lixo
- Ranking de quem mais tirou o lixo

## Publicar
1. Rode `supabase_setup.sql` no SQL Editor do Supabase.
2. Publique `index.html`, `manifest.json` e `sw.js` em uma hospedagem HTTPS.
3. Envie o link pelo WhatsApp.
4. Cada morador cria sua conta.
5. No celular, use "Adicionar à tela inicial" para instalar como app.
